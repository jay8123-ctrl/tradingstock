# Reports Directory

Stores nightly research outputs (`tonight.json`), audit summaries, and one-page morning briefs.

## Conventions
- Every strategy/backtest report must state the **total number of ideas tried** at the top.
- **Rejected ideas stay in the summary table** alongside their rejection reason.
- Every number must include its reproducing command, file path, and line number. Unmeasured metrics must be written as `"not measured"`.
